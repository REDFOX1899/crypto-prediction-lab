How bids become asks

A YES bid is an offer to buy YES. A NO bid is an offer to buy NO. Kalshi publishes bids for both sides.

A 40¢ NO bid corresponds to a 60¢ YES ask, with the same quantity: 100¢ − 40¢ = 60¢. Similarly, a 35¢ YES bid corresponds to a 65¢ NO ask.

These are displayed prices before fees; the available quantity can change.

03 / CO-MOVEMENT

How closely did their returns move?

Correlation uses consecutive synchronized sample returns, never price levels. Gaps and unchanged source timestamps are excluded. +1 means moving together, −1 means opposite. A short sample describes this period; it does not predict the next contract.

READ THE EVIDENCE

A different question at every scale.

  1. Did the outcomes align?Compare official YES / NO results at the same closing time. Shared direction describes history; it is not a new forecast.
  2. How did the quotes move?Select a window, then an asset. Stored one-minute YES ask candles show available quote ranges, with missing minutes left empty.
  3. What moved around them?Compare BTC, ETH and SOL aggregate returns from the same starting observation. CMC prices remain separate from the contract reference.
  4. How much evidence is there?Read the coverage, sample count and timestamps alongside every comparison. A short or stale sample needs care.
